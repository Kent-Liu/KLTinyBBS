# KLTinyBBS

> 一個直接跑在 Meshtastic 節點上的輕量 BBS 模組——不需要外掛樹莓派，不需要接電腦，連太陽能節點也能用。

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

---

## 緣起

早就知道有搭配 Python 的 BBS 開源工具，但外掛電腦或樹莓派在緊急或離網情境下停擺的機會實在太高。[LoBBS](https://github.com/MeshEnvy/lobbs) 給了很大的啟發——直接讓節點本身 host BBS 才是正解。

仔細研究 LoBBS 後，發現它的儲存設計對 nRF52 系列不太合適，頻繁寫入容易造成 Flash 過度磨損，進而影響硬體壽命。於是在致敬 LoBBS 帳號、郵件、新聞功能概念的基礎上，重新設計了這個模組（**非 fork 自 LoBBS**），加入更適合嵌入式環境的儲存機制，讓 nRF52 與 ESP32 都能安心長期運作。

---

## 特色

- **跨平台**：支援 nRF52 與 ESP32，連太陽能供電的節點也沒問題
- **Flash 友善**：採用 A/B 輪寫機制，盡量減少 nRF52 有限 Flash 的損耗
- **完整 UTF-8 支援**：中文、多國語言訊息一樣能正常顯示與截斷
- **Private 模式**：設定密碼鎖定 BBS，只讓家人或特定小圈圈使用（家庭專屬聯絡站！）
- **新信提示**：登入時若有未讀郵件，會出現 ✉️ 提示
- **訊息長度警示**：發文或私訊超過長度限制時，會告知超出比例，不會讓訊息悄悄消失
- **自訂歡迎語**：管理者可設定登入歡迎詞，適合在緊急時傳達重要訊息

> nRF52 平台因資源限制，帳號數（上限 8）、訊息儲存空間（2 KB）與 ESP32（32 帳號 / 16 KB）相比較小，請依部署環境評估。

## ⚠️ 首次安裝後請務必

**立即變更預設 admin 密碼！**

預設密碼為 `12345678`，燒錄完成後請第一時間進入 admin 模式並修改：

```
/admin 12345678
/admin pass 你的新密碼
/admin bye
```

不改密碼等於大門敞開，後果請自行負責 😅
